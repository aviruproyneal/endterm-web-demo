# VELORA Online Shop

## Project Topic

VELORA is a responsive multi-page online shopping website for fashion, beauty, and technology products, now enhanced with dynamic interactivity.

## Group Members

- IT-2513 Narges Jowkar
- IT-2513 Avirup Roy
- IT-2513 Zhanbolat Tulepbergen

## Project Description

VELORA is an online shop designed to provide different types of products in one website. The website contains separate collections for clothes, gadgets, and cosmetics.

The project was created using HTML, CSS, Bootstrap, JavaScript, and jQuery. It is designed to work on desktop, tablet, and mobile screen sizes, and now includes dynamic search, form validation, an image gallery lightbox, and a CRUD management table.

## Features Implemented

**Midterm Features:**
- Six connected web pages
- Navigation bar available on all pages
- Responsive header and footer
- Clothes, gadgets, and cosmetics product collections
- Product cards with images, names, and prices
- Featured products section
- Product comparison table
- Contact form
- Flexbox layouts
- CSS Grid layouts
- Bootstrap responsive grid
- Bootstrap utility classes
- Responsive design using media queries
- Hover and focus effects
- CSS `:nth-child()` pseudo-class
- CSS variables
- CSS positioning
- Google Fonts
- Lazy loading for product images

**Endterm Features:**
- **Form Validation**: Real-time password strength indicator, email RegEx validation, and password matching.
- **Dynamic Search & Filter**: Search bar and category buttons that filter products instantly without reloading.
- **CRUD Operations**: An admin page where users can Create, Read, Update, and Delete product data dynamically.
- **Image Lightbox Gallery**: Clicking a product image opens a lightbox with fade-in/fade-out transitions and next/prev navigation.
